descripcióndescription

perilla es una biblioteca de piruetas para leer perillas (potenciómetros) con microcontroladores, y mapear su valor a otro rango. funciona con placas Arduino y Raspberry Pi Pico, tanto desde Arduino como desde el Pico SDK.perilla is a piruetas library for reading knobs (potentiometers) with microcontrollers, and mapping their value to another range. It works with Arduino and Raspberry Pi Pico boards, both from Arduino and from the Pico SDK.

característicasfeatures

lee una entrada análoga y mapea el valor a otro rango (ej. de 0-1023 a 0-100).
4 ejemplos para Arduino y para Pico SDK: leer, brillo de un led, umbral y dos perillas.Reads an analog input and maps the value to another range (e.g. from 0-1023 to 0-100).
4 examples for Arduino and for Pico SDK: read, LED brightness, threshold and two knobs.
