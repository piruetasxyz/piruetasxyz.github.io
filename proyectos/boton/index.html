descripcióndescription

Boton es una biblioteca de piruetas para leer botones con microcontroladores, con antirrebote incluido. funciona con placas Arduino y Raspberry Pi Pico, tanto desde Arduino como desde el Pico SDK.Boton is a piruetas library for reading buttons with microcontrollers, with built-in debouncing. It works with Arduino and Raspberry Pi Pico boards, both from Arduino and from the Pico SDK.

característicasfeatures

el botón va entre una patita digital y tierra (GND), sin resistencia externa: usa el pull-up interno.
5 ejemplos para Arduino y para Pico SDK: leer, encender un led, alternar un led, contar pulsaciones y dos botones.The button goes between a digital pin and ground (GND), with no external resistor: it uses the internal pull-up.
5 examples for Arduino and for Pico SDK: read, light an LED, toggle an LED, count presses and two buttons.
