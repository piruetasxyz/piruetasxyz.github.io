descripcióndescription

kicad-retrata es una acción de GitHub de piruetas que retrata proyectos KiCad: en cada push genera una captura SVG del esquemático y de la placa de la revisión activa de cada módulo, regenera la tabla de bill of materials en su documento Markdown y, si algo cambió, hace commit. así la documentación del repositorio nunca queda atrás de los archivos de KiCad.kicad-retrata is a piruetas GitHub Action that captures KiCad projects: on every push it generates an SVG of the schematic and the board of each module's active revision, regenerates the bill of materials table in its Markdown document and, if anything changed, commits it. That way the repository's documentation never falls behind the KiCad files.

característicasfeatures

se configura con un kicad-retrata.yml en la raíz del repositorio, con un módulo por placa.
corre KiCad 10 dentro de Docker, con soporte para fuentes privadas guardadas como secretos.
no hace commits vacíos: ignora los SVG en que solo cambió la fecha de exportación.
la usan los repositorios de chufe y chufebu.Configured with a kicad-retrata.yml at the repository root, with one module per board.
Runs KiCad 10 inside Docker, with support for private fonts stored as secrets.
No empty commits: it ignores SVGs where only the export date changed.
Used by the chufe and chufebu repositories.
