descripcióndescription

kicad-visor es una biblioteca de Python de piruetas para documentar proyectos KiCad: exporta esquemáticos, cada capa de la placa, renders 3D y videos de la placa girando en un loop perfecto, y arma con todo eso un sitio web. nació como la herramienta con que piruetas documenta sus propias placas.kicad-visor is a piruetas Python library for documenting KiCad projects: it exports schematics, every board layer, 3D renders and seamlessly looping turntable videos of the board, and builds a website out of all of it. It started as the tool piruetas uses to document its own boards.

característicasfeatures

se usa desde la línea de comandos (kicad-visor export, kicad-visor turntable) o desde Python.
videos girando en los ejes x, y o z, en formato horizontal, vertical o cuadrado, con fondo de color o transparente.
la cámara se ajusta sola para que la placa quede siempre en cuadro, sea cual sea su forma.
un workflow de GitHub Actions publica el sitio en GitHub Pages en cada push.Use it from the command line (kicad-visor export, kicad-visor turntable) or from Python.
Turntable videos around the x, y or z axis, in horizontal, vertical or square format, over a color or a transparent background.
The camera fits itself so the whole board is always in frame, whatever its shape.
A GitHub Actions workflow publishes the site to GitHub Pages on every push.
